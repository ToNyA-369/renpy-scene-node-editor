# Build your first Scene Node project

[繁體中文](../zh-TW/FIRST_PROJECT.md) · [English](FIRST_PROJECT.md) · [Home](../../README.en.md)

This tutorial builds a minimal complete interaction: the player sees “Open the door”, selecting it increments an action counter, plays Content, and moves to a second node.

## 1. Install

1. Create a blank project in the Ren'Py Launcher.
2. On macOS, double-click `安裝到RenPy專案.command` at the repository root.
3. Select the project folder or its `game/` folder.
4. The editor opens and creates the ROOT node.

If macOS blocks the first launch, right-click the installer in Finder and choose Open.

## 2. Confirm the Runtime entry point

The installer normally connects an untouched Ren'Py template automatically. If `script.rpy` already has a custom `label start`, preserve it and add this call at the appropriate point:

```renpy
call scene_runtime_start()
```

Do not create a second `label start`.

## 3. Configure the ROOT node

Open Nodes:

1. Change Name to “At the door”.
2. Select a Background from `game/images/`, or keep `None`.
3. Leave Scene Screen empty for now.

Background is the scene image. Scene Screen is an optional HUD or interface shell that you write in a creator-owned `.rpy` file.

## 4. Create a player Option

Open Options and add a Text Box:

1. Set the Element Name to “Actions”.
2. Add one Item.
3. Set both Name and Text to “Open the door”.
4. Enter `open_door` as the Trigger.

The editor stores `Action:open_door`. An Option only returns a Trigger; it does not run Content, Effects, or GOTO itself.

Form mode edits content and interaction. Use the center handle or `Command+.` / `Ctrl+.` to switch to Canvas mode for position, size, and appearance.

## 5. Create a Stat

Open State and add a Stat:

```text
ID      action_count
Name    Action count
Init    0
Min     0
Max     999
```

The ID is a stable technical name. You may change the display name, but should not directly rename an ID already referenced by Events.

## 6. Create Content

Open Content and create “Open door content”. The editor creates an `.rpy` file and a label. Change the body to:

```renpy
label content_open_door:
    "The door opens."
    return
```

The actual label ID may be generated by the editor. Keep that ID and edit the Ren'Py statements inside the label.

The Event Content picker shows `.rpy` files first and labels second. The Event stores the label name, not the filename.

## 7. Create the destination node

Open the node drawer and create a node named “Beyond the door”. It may have no Options yet; you can add return or exit interactions later.

The Event picker shows the display name while saving the stable node ID.

## 8. Create the Event

Return to the ROOT node and add an Event:

```text
Name       Open the door
Trigger    Option → Open the door
Priority   3
Weight     1
Once       False
```

Add an Effect:

```text
stat → Action count → + → 1
```

Select the Content label you created, then set:

```text
End up      GOTO
Next Node   Beyond the door
```

The complete flow is now:

```text
Option → Action:open_door → Event → Effect → Content → GOTO
```

## 9. Understand the flow results

- `REDO`: stay in the current node and show its Options again after Content returns.
- `GOTO`: enter another node and push it onto the Scene Stack.
- `EXIT`: leave the current node and return to its parent; EXIT at ROOT ends the Runner.

## 10. Validate and run

1. Open Check Project.
2. Fix all errors and relevant warnings.
3. Wait for the saved status.
4. Launch the game from Ren'Py.
5. Select “Open the door” and confirm that Content plays before the destination node opens.
